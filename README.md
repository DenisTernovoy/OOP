# Введение в ООП

## Описание:

Введение в ООП. Домашнее задание 14.1 - это домашнее задание по описания основных сущностей и инициализации объектов.

## Установка:

1. Клонируйте репозиторий:

    ```
    git clone https://github.com/DenisTernovoy/OOP.git
    ```

2. Выберите *Poetry* в качестве интерпретатора.

## Инструкции по работе с проектом

1. Запустите файл main.py из пакета src.
2. Получите все указанные данные.

## Функционал работы

В данной работе были реализованы 2 класса (сущности): Product и Category. У этих сущностей сразу определены поля.

Для класса Product определены следующие свойства:
* Название (name),
* Описание (description),
* Цена (price),
* Количество в наличии (quantity).

Для класса Category определены следующие свойства:
* Название (name),
* Описание (description),
* Список товаров категории (products).

Также для класса Category добавлены два атрибута класса. 
Доступ к этим атрибутам есть у каждого объекта класса, и в них хранится общая информация для всех объектов. 
Эти атрибуты хранят в себе количество категорий и количество товаров.

Атрибуты класса заполняются автоматически при инициализации нового объекта.

Класс Product имеет 2 дочерних класса: Smartphone и LawnGrass.

Помимо имеющихся свойств в родительском классе в Smartphone есть:
* Производительность (efficiency),
* Модель (model),
* Объем встроенной памяти (memory),
* Цвет (color).

В классе LawnGrass:
* Страна-производитель (country),
* Срок прорастания (germination_period),
* Цвет (color).

В классе Product реализован метод `add()`, позволяющий находить сумму стоимости товаров с учетом их количества.
Складывать возможно только продукты одинаковых классов. 

В классе Category реализован функционал (метод `add_product()`), позволяющий добавить новый товар в категорию. 
Добавить товар можно только в том случае, если он является наследником класса Product.

## Тестирование

Для тестирования функций используется фреймворк `pytest`.
В пакете `tests` созданы тесты для каждого отдельного модуля проекта, что позволило обеспечить 100% покрытие функционального кода.
